One funny name for make.fun's "Name the Robot Band": a band made of
robots, plus a few words on its hit song, all under 200 characters.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line
(1–200 characters), and writes the same bytes on every run.
